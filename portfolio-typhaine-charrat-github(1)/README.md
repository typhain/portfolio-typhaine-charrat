# Portfolio de Typhaine Charrat

Version statique du site **Rêveries sentimentales — Cosmoplastie du sensible**.

## Publication avec GitHub Pages

1. Créez un nouveau dépôt GitHub, par exemple `portfolio-typhaine-charrat`.
2. Décompressez l’archive et déposez **le contenu du dossier** à la racine du dépôt.
3. Dans GitHub, ouvrez **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez la branche **main**, le dossier **/(root)**, puis cliquez sur **Save**.

Le site sera publié à une adresse du type :
`https://votre-identifiant.github.io/portfolio-typhaine-charrat/`

## Nom de domaine personnalisé

Dans **Settings → Pages → Custom domain**, renseignez votre domaine. GitHub indiquera ensuite les enregistrements DNS à configurer chez votre registrar.

## Structure

- `index.html` : page principale
- `styles.css` : styles et mise en page responsive
- `site.js` : navigation et agrandissement des images
- `assets/` : photographies et visuels du portfolio

Le site ne nécessite ni compilation, ni dépendance, ni serveur applicatif.
